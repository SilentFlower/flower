# 后端代码评审清单

> 继承通用清单,以下是后端专项重点。

## 数据库

- 是否有未走索引的查询(WHERE 字段、ORDER BY 字段)
- 是否有 SELECT *(应该明确字段)
- 事务边界是否合理(短事务原则、避免事务里调外部 API)
- 是否处理了主从延迟(写完立即读应走主库)

## 并发

- 共享状态是否加锁;锁粒度是否过大
- 异步任务是否有超时
- 重试逻辑是否幂等
- 是否有 goroutine / thread / coroutine 泄漏

## API 设计

- 是否符合团队 REST / RPC 规范
- 是否做了入参校验(必填、长度、格式)
- 错误响应格式是否统一
- 是否考虑了向后兼容(删字段、改字段类型属于破坏性变更)

## 可观测

- 关键路径是否有日志(进入 / 退出 / 错误)
- 日志是否带 traceId / requestId
- 是否埋了关键业务指标(QPS / 成功率 / 耗时)

## 配置

- 环境相关配置不能硬编码,应通过配置中心 / 环境变量
- 敏感配置(密钥)不能进 git
