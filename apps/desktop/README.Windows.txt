Flower Desktop · Windows x64

双击 Flower Desktop.exe。请保留 EXE 旁边的 resources 和其他文件。
进入工作台后可以离线选择目录、创建会话和查看本机历史。点击侧栏工作区可通过系统目录选择器切换，WSL 目录可从资源管理器左侧的 Linux 节点选择。再次浏览会从当前或最近使用的工作区开始。
点击首页的任务建议可将其填入输入框，已有文字会保留。检查或编辑后按发送键执行。
侧栏支持折叠、后退和前进。点击侧栏「搜索会话」或按 Ctrl+K 展开搜索框，输入会话名或工作区即可搜索，按 Esc 收起，搜索框右侧的筛选按钮可按状态（进行中、待批准）和工作区筛选，点击 Flower 头像可返回助手首页。
点击侧栏右上角的按钮切换显示方式。「会话模式」平铺所有对话，「工作区模式」按本机目录分组。点击目录名可展开或收起会话，重启后沿用上次的显示模式。在会话或工作区上右击，也可点行末的「…」，可置顶、重命名、删除会话或移除工作区。移除工作区会清除该组的本地会话，磁盘项目文件会保留。空工作区仍可从菜单新建会话。
点击标题栏下方、聊天区右上角的「打开文件浏览器」，即可浏览当前会话的工作区。点击文件可预览 Markdown 报告、图片、PDF、Word 正文（.docx）、Excel 工作簿样本（.xlsx）、CSV/TSV 表格和常见源码或文本。PDF 支持逐页翻阅。生成报告后也可点击消息里的「预览」。宽窗中打开面板时窗口会向右扩展，聊天区宽度不变，收起后窗口还原。拖动面板靠聊天区一侧的边缘可调宽，点击面板右上角的放大图标可展开阅读，再点一次还原。拖动面板标题栏空白处可将面板放到聊天区左侧或右侧，松手生效，按 Esc 取消；也可点标题栏的双箭头按钮切换，位置在重启后保留。面板中的「Git 变更」可查看当前分支、已暂存和未暂存文件，点击文件可逐行查看差异。WSL 工作区使用对应发行版的 Git。
点击侧栏底部的「本机工作台」打开「模型设置」。右上角「外观」可预览和保存外观模式、配色及首页文案。
首次打开「模型设置」直接进入服务配置。填写服务名称、OpenAI 兼容 Base URL 和可选的 API Key。
配置后可从「当前服务商」切换服务或选择「添加服务」。服务商旁的铅笔管理连接地址和 Key。「添加模型」可读取模型列表或手动填写模型名，保存后可在模型卡中切换。
输入框右下角的模型按钮可切换已保存的服务和模型。支持推理的模型显示强度滑块，可拖动或用方向键变更档位。回转箭头恢复服务默认值。点击滑块上方的模型名进入模型列表，从列表底部打开「模型设置」。
模型卡右侧的铅笔可查看推理推荐与档位。已保存模型会保留同一服务明确声明的档位，重启后可直接使用。更新服务地址或 Key 后可重新读取模型列表。默认档由服务决定。
「推荐」使用服务已声明的档位，或从随应用提供的 pi 本地模型目录识别。未声明档位时，pi 为 Claude Sonnet 5.5 提供低、中、高、很高、最高；具体支持情况取决于所选网关。DeepSeek Flash 支持低、高、最高，直连官方 API 时另有关闭档。
选择「手动」后可勾选网关支持的档位。选择「服务默认」可省略推理参数。策略按服务和模型保存。
填写服务要求的 API 路径，例如 http://127.0.0.1:11434/v1。远程地址使用 HTTPS。
任务发送到当前服务的地址。模型 Key 按服务加密保存。更换已有服务的 Base URL 时，请为新地址重新填写所需 Key。
输入框左下角的权限按钮显示当前模式，展开后可按图标和名称选择，勾选项为当前权限。默认「自动审批」可直接生成报告。「只读」用于浏览、读取和分析。「写入前询问」会列出即将新建的文件，供你同意一次或拒绝。
切到其他会话时，侧栏用「待批准」标记等待中的任务。切回原会话可继续处理。
按 Enter 提交，按 Shift+Enter 换行。可以展开执行步骤、取消任务、继续追问和打开交付文件。
助手回复支持 Markdown。点击回复旁的复制按钮可复制原文。点击网页链接或聚焦后按 Enter，即可在默认浏览器打开。回复中的 HTML 和图片标记以原文显示。
点击输入框的加号，可以添加本地文件、从工作区引用文件、粘贴剪贴板图片，或选择和切换工作区。「添加本地文件」支持从电脑上的任意目录多选。也可直接拖入文件，或在右栏文件旁点加号、在预览中点「加入对话」。输入框支持直接粘贴截图。发送前可逐个移除，每条消息最多 8 项。已发送的附件随消息显示。外部附件和粘贴的截图保存在本次会话的本机资料中。草稿和已发送消息可以点击文本、表格、文档附件在右栏阅读。两处都会显示等比例图片缩略图，点击查看大图，可进一步放大或按 Esc 返回。
PDF 读取文字层并标注页码，Excel 提供工作表和单元格位置，Word 提取正文；支持图片输入的模型可查看 PNG、JPEG、WebP。需要交付时可请 Flower 生成 Markdown 核对报告，再从消息中预览。
交付文件保存在当前工作区。重启后可回读本机历史。
默认资料位于 %APPDATA%\Flower Desktop Open。
