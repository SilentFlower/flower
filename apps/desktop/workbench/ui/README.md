# Flower Desktop 界面组件

首页参照 Cindy 的暖灰侧栏、左对齐的头像字标、双层编辑卡和纵排任务建议。侧栏仅新建会话固定在顶部，工作区、搜索、助手与会话列表共用一个滚动区。主页、会话行、回复、设置和主题预览沿用 Flower 的组件，Windows 窗口控制保留在标题栏覆盖层。

| Toast | 复制成功、操作失败、读取历史失败、队列发送失败、压缩结果等瞬时提示显示在标题栏下方右侧：最多 3 条，同文案同色调去重并重新计时，悬停或焦点在内时暂停，可手动关闭；普通 4 秒，错误与带操作的 8 秒。区域礼貌播报，错误立即播报；减弱动效时无滑入动画。 | [toast.js](toast.js)、[renderer.js](../renderer.js) 的 `action` |

新请求的原话和附件由桌面 Host 与共享核心快照一起落盘，按请求 ID 恢复。模型继续收到附带已授权相对路径的输入。早期记录没有独立附件字段，界面保留已存文字。

侧栏、主会话区与右栏使用 `flowerUI.softScroll` 的自动隐藏细滚动条（[foundation.js](foundation.js)）。这些容器不能再设置 `scrollbar-width`，否则 `::-webkit-scrollbar` 样式失效、回到原生滚动条。会话导航条的刻度列表只有 28 像素宽，12 像素的滑块会挤占命中区，因此用 `scrollbar-width: none` 完全隐藏滚动条，靠滚轮和当前刻度自动滚入视野定位。

会话版式参照 Cindy：消息列正文最宽 914 像素、两侧固定留白 50 像素，输入框比消息列左右各宽 10 像素（最宽 934）；会话区窄于 700 像素时留白收到 20 像素。按会话区实际宽度（容器查询）而非窗口宽度切换，首页编辑卡保持原有尺寸。

流式更新复用请求节点。处于底部时跟随输出，向上阅读时保留滚动位置，离开底部时会话区底部渐隐到输入框，输入区上方出现「回到底部」，期间有新内容时展开为「↓ 新消息」胶囊。文件浏览器开关浮在会话区右上角（右栏停靠左侧时在左上角），不单独占行，内容从其下方滚过。更新工具结果时保留折叠状态和焦点。切换会话时重新挂载该会话内容，恢复其输入草稿和上次的阅读位置。重启恢复历史文字、请求状态、工具步骤与交付文件。

瞬时提示用 Toast，表单与审批内的反馈用原位状态区域，都使用语义 token。设置的「全局指令」保存个人口径（最多 4000 字），与工作区根下的 FLOWER.md（最多读取 8000 字）依次附加在系统提示之后。Host 接入真实审批事件后，再增加可键盘操作的审批控件。交付类型扩展时在文件组件补对应标签和动作。每个新增状态应有真实调用点，并沿用窄窗、中文输入、切换会话和 Windows 回环验收。

正文与标题统一采用随应用分发的 HarmonyOS Sans SC 可变字体（[fonts/](fonts/)），缺失时回退到 Microsoft YaHei UI 与 Segoe UI。字体按华为许可原样分发，不做子集化或格式转换，外观设置预览区标注字体来源。


## 会话修订与分享

- [变更卡](turn-changes.js)懒加载当前请求的工具账本。详情沿用交付卡的宽度与表面，操作完成后回到标题焦点。实际撤销通过 Host 原生确认和文件身份核验。
- [会话操作](conversation-actions.js)将修订预览、导出和分享放在真实消息与会话入口。普通阅读态隐藏选择控件，图片选择按提问、插话和各段回复分别勾选。预览和保存弹窗使用原生焦点循环，长文件名换行。
- [提问卡](ask-user.js)按当前运行显示单项或多项选择。等待时，消息标题只显示一处「待回答」。切换会话保留未提交的选项，终态释放旧卡。
- [应用更新](conversation-actions.js)在工作台顶栏显示后台下载进度，点击后进入设置的「应用更新」。详情显示已下载和总大小。更新源未提供字节数时显示不定进度。下载完成并准备好安装后，工作台显示可点击的就绪提醒；Windows 窗口最小化或收到托盘时改用系统通知。任务处理期间可安排退出时安装，待空闲后可立即重启。

## 主题与表单

工作台按 flower2api 的主题种子和语义控件组织。浅色、深色和跟随系统共用六组品牌色。用户可以单独指定强调色、成功色、错误色及两处首页文案。颜色派生时按当前背景计算对比度。原生标题栏随模式切换。

- 工作台组件使用 `--surface`、`--ink`、`--accent`、`--on-accent`、`--good` 和 `--danger` 等语义色。[主题运行时](theme-preload.js)
- 设置页使用原生 `dialog.flower-settings`、`.settings-field`、`.settings-actions` 和现有按钮。主题面板演示分段选项、预设色卡、取色器、文本字段和草稿预览。[设置控件](theme-settings.js) · [共享样式](theme.css)
- 首帧从本机读取偏好。修改实时预览，保存写入本机。取消或 Esc 恢复打开时的偏好，再将焦点还给设置入口。
