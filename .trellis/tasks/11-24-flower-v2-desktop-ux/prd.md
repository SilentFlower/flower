# Desktop 交互打磨（借鉴 Cindy 与 QoneAgent）

## 目标

Flower Desktop 的首页、侧栏、面板停靠和模型选择已对齐 Cindy 与 Qone。剩余差距集中在任务运行之后：进度是否可见、多任务时谁来提醒、出错或说错后如何修正、长对话如何找回。本任务按三档逐个交付，每档独立规划、实现、验收。

来源对照与证据：[research/cindy-qone-ux-gap.md](research/cindy-qone-ux-gap.md)

## 任务图

| 子任务 | 范围 | 状态 |
|---|---|---|
| [第一档](../11-24-flower-v2-desktop-ux-tier1/prd.md) | 运行过程可读化、多任务提醒、消息操作、阅读位置、回复中文件路径、右键菜单、长粘贴折叠、历史输入召回、窗口状态持久化 | 规划中 |
| [第二档](../11-24-flower-v2-desktop-ux-tier2/prd.md) | 选中引用追问、队列编辑与插话、上下文用量与压缩展示、会话正文搜索、@ 提及与拖入、中断恢复、交付卡片元信息、Toast、全局指令 | 待第一档完成后规划 |
| [第三档](../11-24-flower-v2-desktop-ux-tier3/prd.md) | 本轮变更撤销、编辑重发与回退分叉、结构化提问卡、导出与复制为图片、应用内更新 | 待第二档完成后规划 |

## 跨档约束

- 档位顺序执行。后一档在前一档提交后再规划，以免基于未落地的代码设计。
- 第二档的上下文用量展示建立在 `11-23-flower-v2-desktop/context-continuity.md` 的占用估算之上，不重复实现估算。
- 沿用 Flower 工作台的语义 token、焦点样式、窄窗 660 像素、深浅色、中文输入法、切换会话与 Windows 实机验收惯例（见 `apps/desktop/workbench/ui/README.md`）。
- 系统减弱动效时，新增动效全部降级为静态反馈。

## 跨档验收

- 每档完成后，Desktop 全仓测试、类型检查与 Biome 检查通过，Windows 候选实物完成工作台主流程回归。
- 三档完成后，对照研究文件逐项标注已交付、调整或放弃的理由。

## 不做

终端、内置浏览器、子代理与后台任务、Goal 模式、语音输入、全局截图、AgentIsland、机器人、计费、技能市场、远程控制。
