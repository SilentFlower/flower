# Flower Desktop 开源工作台

`v2` 的 Windows 应用启动后直接进入工作台。用户可在离线时选择本机目录、创建会话、编辑任务和查看已保存的交付物。运行模型任务时，用户提供自己的 OpenAI 兼容服务地址、模型名和该服务所需的密钥。企业员工身份及企业网关适配归属 `v2-company`。

## 界面和设置

- 左侧工作区和会话列表在滚动或鼠标移入右缘时显示滑块，停止操作约两秒后隐藏。输入框加号可添加本地文件、引用工作区文件、粘贴剪贴板图片或切换工作区；三档权限有各自的图标和明确的选中标记。

- 以用户提供的 Cindy 桌面截图为首页参照。使用暖灰侧栏、浅色编辑卡、Flower 自有头像与字标。Windows 保留原生窗口控制。
- 任务输入采用上下两层。附件及目录操作放在底部左侧，旁边显示当前会话权限。模型选择紧挨右侧发送键。点击当前模型可以更换后续任务所用的模型。
- 输入框旁显示模型图标。选择支持推理强度的模型后，可在小面板上点击、拖动或用键盘调整档位。头像随档位移动，系统减弱动态效果时保留清晰的选中反馈。选择强度应改变后续模型请求。
- 从本机设置进入「模型」或「外观」。模型页可管理多个 OpenAI 兼容服务、发现或手动添加模型并查看当前选项。服务地址、密钥、模型与推理设置随重启恢复。已有单服务配置可继续使用。
- 模型设置沿用 Flower 工作台的表面色、字号、留白、图标和焦点样式。服务商菜单及模型能力控件支持键盘、浅色和深色。在已有模型的设置页中，应能一眼辨认当前模型与编辑入口。
- 已知模型经 OpenAI 兼容网关使用时，可直接采用随应用提供的推理预设。编辑时能看到推荐档位，并可按服务单独覆盖或关闭。旧版手工保存的档位继续生效。
- 助手回复按 Markdown 排版，流式回复和历史记录共用同一显示方式。中文段落、加粗、列表、代码和表格融入当前主题。用户输入及本机历史保留原文。
- 会话工具权限有「只读」「写入前询问」「自动审批」三档，作用于选定工作区。只读允许分析，写入前询问可逐次同意或拒绝新建报告。已有会话沿用原有自动审批行为。
- 首页提供与实际工具匹配的四个任务建议，点击后可继续编辑。侧栏可收起、展开、搜索历史会话，并可从 Flower 助手入口回到首页。
- 侧栏可输入 Windows 和 WSL 工作区路径，确认后可查看目录及恢复会话。
- 侧栏右上角可切换「会话模式」和「工作区模式」。会话模式平铺所有会话，工作区模式按会话所在的本机目录分组。同名目录可区分。切换时保留当前对话、草稿及待审批任务，重启恢复上次使用的模式。
- 标题栏下方、聊天区右上角的按钮直接打开工作区文件浏览器。逐级浏览目录，可预览 Markdown、常见源码与图片、PDF、DOCX 正文、CSV/TSV 及 Excel 样本。面板可以放大阅读，PDF 可以翻页。消息中的交付文件可直接进入预览。窄窗覆盖显示，宽窗并排并可调宽，切换会话时跟随工作区。
- 参考 flower2api 的主题种子、语义色、基础控件、草稿预览与保存。工作台和设置页使用同一套按钮、表单、弹窗、焦点和反馈样式。
- 主题设置提供跟随系统、浅色和深色模式。用户可选预设或自定义强调色、编辑首页标题和任务输入框提示。保存后重启恢复已选外观，取消时恢复进入设置前的状态。

- 从文件列表或预览引用工作区资料；原生多选及拖放也能引用工作区外的单个文件。粘贴的截图和图片附件在草稿及历史中展示缩略图，点击放大，支持键盘关闭，发送前逐项移除；消息保留所用资料。支持 PDF、DOCX、Excel、图片、文本资料的模型输入，核对结论可按原权限交付带来源的 Markdown 报告。

## 右栏停靠与窗口扩展

- 宽窗中打开文件或 Git 面板时，原生窗口向右扩出栏宽，左栏、聊天区和输入框保持原有位置与宽度。收起后还原窗口，反复开关不累积偏移。
- 扩展只使用窗口所在显示器的可用工作区并换算缩放。右侧空间不足时先向左挪出缺口，仍不足时由聊天区让出余下宽度，窗口不会被推出屏幕。最大化、全屏和窄窗不扩展窗口，右栏沿用原有的并排或覆盖显示。展开期间用户移动或调宽窗口，收起时只减去扩出的宽度。
- 拖动面板标题栏空白处可将面板放到聊天区左侧或右侧。拖动时高亮落点，松手生效，Esc 取消。点击标签、按钮或输入内容不触发拖动，调宽仍使用面板边缘。标题栏按钮提供同样的键盘操作。停靠位置随重启恢复，移动时保留当前文件、预览和 Git 内容。左右停靠共用已扩展的窗口，换位只交换面板与聊天区，聊天正文和输入框保持可用宽度。

## 交付验收

- 在全新、无配置的资料目录双击启动，能直接选目录和建会话。账号服务及模型服务均不参与启动。
- 用户准备提交模型任务时，可设置模型并继续原工作。Windows 凭据保护由 Host 使用。模型服务可按需使用密钥或本机免密访问。
- 在草稿中从模型列表切换，检查后续请求携带所选模型，确认附件、草稿和键盘操作。无法读取模型列表时可手动指定。
- 用真实桌面入口调用受控的本机模型服务，验证 pi 的流式回复、工具、取消和历史回读。Excel 用例生成报告和汇总表，四行合计 500，A、B 各 250。
- 用同一个工作簿验证各权限模式。只读分析返回结果，拒绝或取消写入后没有新文件。每次确认仅授权该次产出。验证会话隔离、模式恢复和运行期间的权限约束。
- 验证主题的即时预览、取消、保存、恢复默认和重启，确认标题栏及设置控件随模式变化。
- 两个版本各自维护用户资料，企业版在自己的分支验收员工准入。
- 在 Windows 隔离资料中记录右栏打开前后的窗口外框、聊天区和输入框几何。覆盖右侧空间不足、最大化、窄窗、手动移动或调宽、反复开关、拖放后的聊天宽度、取消、键盘停靠和重启恢复。

工作区和会话各自支持置顶、重命名和移除；空工作区可继续建立会话。右栏的文件和 Git 视图共用导航与宽度。草稿及消息中的文档可以直接进入阅读，图片缩略图按原比例显示。
