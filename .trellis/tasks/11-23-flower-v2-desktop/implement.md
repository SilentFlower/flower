# 实施与验收

1. 将企业员工登录与固定网关保存在 `v2-company`。开源桌面使用独立本地资料及用户配置的模型端点。
2. 初次打开直接呈现工作台。将模型配置与工作区、会话和历史的加载分开。模型请求经 Host 转发，工具继续使用共享运行时。
3. 让主题设置和模型设置共用表单与弹窗样式。验证配色、自定义首页内容、暗色、取消和保存。
4. 在 Cindy 参考图尺寸核对首页头像、字标、编辑卡及任务建议。验证建议填入、未发送草稿保留、侧栏折叠与搜索，以及首页和有消息的会话之间的切换。
5. 在 Windows 无参数启动正式应用，检查标题栏系统控件、窄窗、工作目录、模型流、产物和重启回读。检查 ASAR 的实际文件和桌面初次启动的网络行为。
6. 使用同名但路径不同的两个工作区及多段会话验证侧栏。检查双视图、新旧会话归组、搜索、折叠、草稿和待审批状态，以及重启后的视图偏好。
7. 在 Windows 隔离资料中验证模型与外观的入口、模型卡和推理强度面板。使用两个受控服务验证凭据归属与请求体，覆盖旧配置、服务默认强度、手动模型、保存重启、键盘及减少动态效果设置。
8. 对照 Qone 的服务商菜单和模型卡，使用与用户截图相同的两个模型复核 Flower 设置总览及编辑页。捕获兼容网关收到的请求，检查内置推荐、未知模型、手动关闭、旧版手动高档及重启。用浅色、深色、窄窗和键盘复核菜单与焦点。
9. 用用户截图中的中文加粗列表复现纯文本显示问题。验证流式分片、加载历史、离线启动、原文保留，以及窄窗中代码和表格的阅读效果。
10. 在隔离工作区验证右侧文件面板的目录分页、报告预览、工作簿样本、键盘调宽和窄窗收起。在 Windows 核对开关相对于标题栏下边缘和聊天区右边缘的位置，打开真实图片、两页 PDF、DOCX、CSV/TSV、源码并验证放大及还原。真实任务生成分析报告后从消息打开预览，返回时恢复原按钮焦点。

11. 用真实 WSL 工作区内的报价 PDF 和预算表核对模型请求中的页码、行号与差价，生成并预览核对报告；测浅深色、窄窗、移除、切换会话、粘贴截图及重启历史。

12. 通过原生多选、系统文件拖放、粘贴和历史恢复验证外部附件、缩略图、放大与关闭焦点；覆盖草稿移除、同名文件及只读文件范围。

从仓根执行 `npm run build`，再运行 `npm run package:windows --workspace @flower-ai/flower-desktop -- <Electron zip> <SHASUMS256.txt> <新目录>` 构建 Windows x64 解压包。

在两个独立的 Windows 与 WSL 仓库中回读暂存和未暂存差异，检查未跟踪文件、工作区切换、置顶与重命名重启恢复、会话删除及空组重新建会话。对已移走原文件的文本和 Word 附件核对右栏预览及焦点返回。

13. 右栏停靠与窗口扩展：Main 增加受信的 `panel-expansion` 处理与最大化待还原，Preload 暴露 `setPanelExpansion`。渲染层增加停靠方向、拖放、键盘停靠、过渡冻结和 `--layout-vw`。补充纯函数单元测试，在 Windows 隔离资料中用 Playwright 记录打开前后窗口外框、聊天区和输入框几何，覆盖右侧空间不足、最大化、窄窗、手动移动或调宽、反复开关、拖放、取消、键盘停靠与重启恢复。临时包与资料放在 D 盘，验收后清理。
