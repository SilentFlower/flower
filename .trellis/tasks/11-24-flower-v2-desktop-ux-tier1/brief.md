# Brief — 第一档 运行可见与操作手感

## Goal

- 让业务用户把长任务交给 Flower 后敢于切走：运行中看得懂进度，完成或需处理时得到提醒，回来后能找回位置、快速纠错，输入与右键符合 Windows 习惯。

## Scope

- R1 运行过程可读化：首包前「正在思考」等待态；工具步骤显示语义动作与目标（「正在读取 预算.xlsx」，附件显示附件名）；一轮结束折叠为「已处理 2 分 13 秒 · 读取 3 个文件、分析 1 个工作簿」摘要；运行中显示最新一句推理（不落盘）；步骤与起止时间随会话保存，重启可见；`analyze_excel` 统一为「分析工作簿」。
- R2 多任务提醒：侧栏状态点（运行中、等你处理、完成未读、失败未读，未读仅本次运行期间）；窗口不在前台时完成、失败、待批准发系统通知并闪烁任务栏，点击回到会话；有未完成任务关窗先确认。
- R3 消息操作：失败、取消、中断、拒绝写入的请求可「重试」（原输入+原附件新建一轮，原记录保留）和「编辑」（放回输入框，有草稿先确认）；成功请求不提供编辑；用户消息可复制；仅当前会话。
- R4 阅读位置：按会话记住滚动位置，贴底会话继续跟随；「回到底部」按钮带新内容标记。
- R5 回复中的文件路径：工作区内相对路径、行内代码路径、工作区内绝对路径可点击预览；右键「预览 / 在资源管理器中显示 / 复制路径」；工作区内本地图片内联并可放大；越界路径保持原文。
- R6 原生右键菜单：输入框剪切/复制/粘贴/全选，选中文字复制，图片复制；文件行与交付卡「在资源管理器中显示 / 复制路径」，支持菜单键。
- R7 长粘贴：超过 2000 字或 20 行、或会使输入框超过 16000 字时，转为会话附件「粘贴的文本（N 行）.txt」，走现有附件管线；超过 1 MiB 或附件已满时提示，不截断。
- R8 历史输入召回：空输入框 ↑/↓ 召回本会话已发输入，越过最新或 Esc 恢复原草稿，修改后方向键恢复默认，输入法组合中不触发。
- R9 窗口状态：记住位置、尺寸、最大化，扣除面板外扩；位置不可见时回落主显示器居中。

## Non-Goals

- 真正替换或删除已成功的一轮对话（第三档）。
- 推理全文保存与回看、任务栏角标计数、托盘、通知设置项、开机自启。
- 未读状态跨重启保存；工作区面板 Markdown 预览中的路径链接。
- 第二档、第三档范围。

## Key Context

- 共享运行时 `packages/agent-runtime`：只加可选字段（`ToolStep`、`RequestRecord.startedAt/endedAt/steps`、事件头 `at`、`tool_started.target`）与可选宿主钩子 `SessionGrant.describeTool`；不新增事件种类，`dual-host.test.ts` 事件序列不变；code-reviewer 宿主须回归；改后需 `npm run build -w @flower-ai/agent-runtime`。
- 每个运行事件都会整份落盘：步骤与时间随已有事件提交，推理走 worker 旁路（按会话绑定 `streamFn`、节流 1 秒的 `reasoning` 帧），不进共享核心。
- 渲染层权限全拒、CSP 只允许 blob 图片：剪贴板、通知、右键、文件定位都经 Main IPC，逐项复核会话、请求、路径（`locate`）。新增 IPC：`retry-request`、`restore-request-draft`、`copy-text`、`show-path-menu`、`paste-text`；新增 `importAttachmentText`、`window-state.mjs`。
- 假 electron 模块（`apps/desktop/testing/workspace-panel.test.mjs`）需补 `Notification` 导出。
- `workbench.json` 在窗口创建后才加载，窗口状态单独存 `window-state.json` 并在创建前同步读取；最大化取 normal bounds。
- 风险：Windows 解压版 toast 可能不显示（兜底任务栏闪烁，如实记录）；跨 DPI 恢复误差（回落保证可见）；无推理流的网关不显示推理。
- 证据：`research/tier1-code-facts.md`（行号以 2026-11-24 11:10 为准，开工时哈希未变）；设计 `design.md`；执行顺序 `implement.md`。

## Acceptance

- AC1–AC3：真实 pi 回环任务首包前有等待态、步骤含动作与目标、结束为含耗时与计数的摘要；推理只在运行中出现且不增加落盘；重启后摘要与步骤一致，旧会话正常。
- AC4–AC6：侧栏状态与已读规则正确；失焦时完成/失败/待批准触发通知与闪烁、点击回到会话、前台与取消不通知（Windows 实机记录 toast 结果）；运行中关窗有确认，取消后任务继续，确认后显示已中断。
- AC7：重试新增一轮带原附件、编辑回填且先确认覆盖、成功请求无编辑、复制得到原话、非当前会话不可操作。
- AC8：长会话切回原位置，贴底会话继续跟随，回到底部按钮与新内容标记可用。
- AC9–AC10：路径点击预览、右键定位与复制、图片内联放大、越界路径不读取；各右键菜单项与键盘打开正确。
- AC11–AC12：2001 字、21 行、超 16000 字的粘贴转附件且进入模型请求，1999 字 19 行留在输入框，超 1 MiB 有提示；↑/↓ 召回与恢复草稿、输入法中不触发。
- AC13：位置尺寸与最大化重启恢复，不含外扩宽度，断开显示器后回到可见区域。
- AC14：Desktop 与 agent-runtime 测试、根构建与类型检查、Biome、code-reviewer 测试通过；窄窗 660、深浅色、减弱动效、中文输入法、切换会话下可用。
