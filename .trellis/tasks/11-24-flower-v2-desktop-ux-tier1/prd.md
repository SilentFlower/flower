# 第一档 运行可见与操作手感

## 目标

让业务用户把长任务交给 Flower 后敢于切走：运行中看得懂 Flower 在做什么，完成或需要处理时得到提醒；回来后能找回阅读位置、快速纠错，日常输入与右键操作符合 Windows 习惯。

来源对照：[父任务研究](../11-24-flower-v2-desktop-ux/research/cindy-qone-ux-gap.md) 的「第一档」九项。代码现状与行号证据：[research/tier1-code-facts.md](research/tier1-code-facts.md)（下文 §n 指该文件章节；行号以 2026-11-24 11:10 为准，实现前复核）。技术方案见 [design.md](design.md)，执行顺序见 [implement.md](implement.md)。

## 现状要点

- 事件链路：pi → `packages/agent-runtime` `recordProgress` → worker → runtime-host → main → renderer（§0）。共享核心只发 7 种事件，工具参数、`durationMs`、thinking 在 `R/index.ts:434-450` 被丢弃，事件与请求记录都没有时间戳（§1.3–1.5）。每个运行事件都会整份落盘（§0、§10.2）。
- 工具步骤只在窗口内存里，重启或切到第三个会话后丢失（§1.7）。`analyze_excel` 的中文名两处不一致（§1.2）。
- 主进程只记录「进行中」和「待批准」，没有完成、失败、未读状态；未使用通知、任务栏闪烁；关窗直接退出并把运行中的任务变成 `interrupted`，无确认（§2）。
- 提交接口只收文本，附件取自当前会话草稿；失败请求不进模型上下文；核心与桌面存储都只能追加，没有截断接口（§3）。
- Markdown 中非 http 链接与图片按原文显示；`workspacePanel.preview(path)` 可预览当前会话工作区内任意相对路径；CSP 只允许 blob 图片；渲染层权限请求全部被拒（§4、§10.7）。
- 没有原生右键菜单与「在资源管理器中显示」（§5）。
- 文本粘贴不拦截，`maxlength=16000` 静默截断；文本附件以内联正文（≤24K 字符）进入模型，外部附件另有 `attachment:` 引用供工具读取（§6）。
- 方向键无处理，当前会话的已发输入可从 `timeline.requests` 取得（§7）。
- 窗口固定 1282×801 创建，不保存位置尺寸；`workbench.json` 在窗口创建后才读取（§8）。

## 需求

### R1 运行过程可读化

- R1.1 提交后、首个内容到达前，回复区显示「正在思考」等待态；系统减弱动效时为静态文字。
- R1.2 工具步骤显示语义动作与目标对象：进行中「正在读取 预算.xlsx」，完成后「已读取 预算.xlsx」，出错标明失败。`attachment:` 引用显示为附件名，路径只显示文件名，悬停可见完整相对路径。五个工具统一中文名，`analyze_excel` 统一为「分析工作簿」。
- R1.3 一轮请求结束后，工具步骤折叠为一行摘要：耗时与按动作汇总的计数，如「已处理 2 分 13 秒 · 读取 3 个文件、分析 1 个工作簿」；失败、取消时分别为「处理失败，耗时 …」「已取消，耗时 …」，同样附动作计数。运行中保持展开，结束后可手动展开查看逐项步骤。
- R1.4 网关返回推理内容时，运行中在回复头部下方单独一行显示最新一句推理（与状态并列会挤压操作按钮）；正文开始输出后隐藏。推理不落盘、不进复制内容、不发送给其他会话。
- R1.5 工具步骤（动作、目标、状态）与请求开始、结束时间随会话保存，重启后摘要与逐项步骤仍可看到。早期没有这些字段的记录照常显示，只是没有摘要。

### R2 多任务提醒

- R2.1 侧栏会话行显示状态：运行中、等你处理（待批准）、完成未读、失败未读。用户在窗口前台查看该会话即视为已读。未读状态只保存在本次运行期间。
- R2.2 窗口不在前台时，任务完成、失败或需要批准写入，发送系统通知并闪烁任务栏，窗口回到前台后停止闪烁。点击通知回到对应会话。窗口在前台时不弹通知；用户主动取消的任务不通知。
- R2.3 有运行中、排队或待批准的任务时关闭窗口，先弹出确认，说明任务数量以及关闭会中断这些任务；选择取消则窗口保持打开、任务继续。

### R3 消息操作

- R3.1 失败、取消、中断、拒绝写入的请求提供「重试」：以原输入和原附件新建一次请求，原记录保留。
- R3.2 上述请求提供「编辑」：原文和原附件放回当前会话输入框，输入框已有未发送内容时先确认覆盖；用户修改后作为新一轮发送。这些请求未进入模型上下文（§3.2），重发后上下文不含旧轮次。
- R3.3 已成功的请求不提供编辑（2026-11-24 决定：真正替换上一轮归第三档）。
- R3.4 用户消息提供「复制」，复制原话。
- R3.5 重试与编辑只作用于当前选中的会话，运行或排队期间按现有提交规则排队；模型不支持图片等现有提交校验照常生效。

### R4 阅读位置

- R4.1 每个会话记住滚动位置，切回时恢复；离开时贴底的会话切回后继续贴底并跟随输出。
- R4.2 离开底部时出现「回到底部」按钮；离开期间有新内容时按钮带提示标记。键盘可达。

### R5 回复中的文件路径

- R5.1 回复里指向当前会话工作区内文件的路径可点击，在右栏预览：Markdown 链接的相对路径、行内代码中带常见文件扩展名的相对路径（文档、表格、图片、常见源码等，`example.com`、`v1.2` 不视为路径），以及位于工作区根下的绝对路径。
- R5.2 路径的右键菜单提供「预览」「在资源管理器中显示」「复制路径」。
- R5.3 回复中工作区内的本地图片 `![](路径)` 内联显示，点击用现有图片查看器放大；读取失败时显示原文。
- R5.4 不在当前工作区、含 `..`、无法解析的路径保持原文，不发起读取。

### R6 原生右键菜单

- R6.1 输入框：剪切、复制、粘贴、全选，按可用状态启用。
- R6.2 选中文字：复制。图片：复制图片。
- R6.3 工作区面板文件行、交付文件卡：右键提供「在资源管理器中显示」「复制路径」，交付文件另含「预览」。键盘的菜单键或 Shift+F10 可打开同一菜单。

### R7 长粘贴折叠

- R7.1 粘贴文本超过 2000 字或 20 行，或粘贴后输入框会超过 16000 字时，自动保存为会话附件「粘贴的文本（N 行）.txt」，不再插入输入框（2026-11-24 决定）。
- R7.2 该附件与其他附件一致：草稿与历史中显示为附件，可预览、可移除，进入模型时按现有附件规则提供内联正文和工具引用。
- R7.3 超过 1 MiB 或附件数已满时给出明确提示，不截断、不丢内容（剪贴板原文保留）。

### R8 历史输入召回

- R8.1 输入框为空时按 ↑ 依次取出本会话已发输入，↓ 返回较新的一条，越过最新一条时恢复原草稿；召回内容被修改后方向键恢复普通光标移动；Esc 退出召回并恢复原草稿。输入法组合中不触发。

### R9 窗口状态持久化

- R9.1 记住窗口位置、尺寸与最大化状态，重启恢复。面板外扩的宽度不计入保存值。
- R9.2 保存的位置已不在任何显示器可见区域时，回落到主显示器默认尺寸居中；尺寸不小于最小窗口。

### 试用反馈补充（2026-11-24）

- R10 工作区模式下，侧栏「工作区」标题行右侧提供「全部折叠 / 全部展开」：有任一分组展开时折叠全部，全部折叠时展开全部；搜索中作用于搜索结果的折叠状态。会话模式下不显示。
- R11 标题行提供「定位当前会话」：展开当前会话所在分组，滚动到侧栏中部并聚焦、短暂高亮该行；当前会话被搜索或筛选隐藏时先清除搜索与筛选；首页没有当前会话时停用。
- R12 主会话区、右栏（文件、Git 变更、预览、差异）与侧栏统一为自动隐藏的细滚动条：静止时不显示滑块，滚动或指针移到右缘时显示，停止约 2 秒后隐藏；深浅色适配；显示与隐藏不改变布局宽度；系统强制颜色模式下保留系统样式。
- R13 右栏样式：文件列表按类型着色图标（目录、表格、PDF、Word、图片、代码、文本），行悬停有圆角底色；Git 变更的状态以彩色标签显示（修改、新增、删除、未跟踪、重命名），删除的文件名划线；分组标题带数量徽标，分支以标签样式显示；差异视图的行号栏有底色，增删行左侧有色条。

## 验收标准

勾选依据见 [verification.md](verification.md)。R10–R13 的验收见 AC15–AC17。覆盖缺口：AC5 的后台状态在私有桌面中以替换 `isFocused` 模拟；AC8 与 AC14 的窄窗、深色在浏览器夹具中验证；AC12 输入法、AC13 显示器断开、AC11 超过 1 MiB 由单元测试覆盖；减弱动效只做了 CSS 审查。

- [x] AC1（R1.1–R1.3）真实 pi 与回环模型下，读取工作簿、分析并写报告的一轮任务：首包前出现等待态；每个步骤显示语义动作与目标文件名，附件显示附件名；结束后折叠为含耗时与动作计数的摘要，可展开逐项。
- [x] AC2（R1.4）回环模型返回 `reasoning_content` 时，运行中在回复头部下方显示最新一句推理，正文开始后隐藏；重启后不出现推理内容；会话文件中没有推理分片的额外写入。
- [x] AC3（R1.5）完成上述任务后重启应用，同一请求的摘要和逐项步骤与重启前一致；无步骤字段的旧会话正常显示。
- [x] AC4（R2.1）A 会话运行时切到 B，侧栏 A 显示运行中；A 完成后显示完成未读，进入 A 后消失；失败与待批准分别显示对应状态。
- [x] AC5（R2.2）窗口失焦时任务完成、失败、待批准各触发一次系统通知与任务栏闪烁；点击通知切到对应会话；窗口在前台时不通知；取消任务不通知。Windows 解压版实机记录通知是否显示。
- [x] AC6（R2.3）运行中关窗出现确认，取消后任务继续完成；确认后退出，任务显示「上次运行已中断」；无任务时直接关闭。
- [x] AC7（R3）失败请求重试后新增一轮且带原附件，原记录保留；编辑把原文与附件放回输入框，有草稿时先确认；成功请求无编辑入口；复制用户消息得到原话；非当前会话不可操作。
- [x] AC8（R4）在长会话中部切走再切回，回到原位置；贴底会话切回后继续跟随；离开底部时出现回到底部按钮，有新内容时带标记，点击或回车回到底部。
- [x] AC9（R5）回复中的工作区相对路径、行内代码路径、工作区内绝对路径可点击预览；右键可在资源管理器中显示和复制路径；工作区内图片内联显示并可放大；工作区外与含 `..` 的路径保持原文且无读取请求。
- [x] AC10（R6）输入框、选中文字、图片、文件行、交付文件卡的右键菜单项与状态正确；键盘可打开文件行菜单。
- [x] AC11（R7）粘贴 2001 字、21 行、使输入框超过 16000 字的文本均转为附件，模型请求含该附件正文；1999 字 19 行的粘贴仍进入输入框；超过 1 MiB 有提示且不截断。
- [x] AC12（R8）空输入框 ↑/↓ 按顺序召回并恢复原草稿；修改后方向键正常移动光标；输入法组合中按方向键不召回。
- [x] AC13（R9）调整位置与尺寸后重启恢复；最大化后重启仍最大化，还原后回到最大化前的尺寸；面板展开时关闭，重启尺寸不含外扩宽度；保存位置所在显示器断开后窗口回到主显示器可见区域。

- [x] AC17（R13）文件列表各类型图标颜色可区分；Git 状态标签颜色与文案正确、删除文件划线；差异视图行号栏与增删色条在深浅色下清晰；窄窗无横向溢出。

- 未读状态跨重启保存。
- 工作区面板内 Markdown 预览中的路径链接。
- 第二档、第三档范围（见父任务任务图）。
