# 第一档 运行可见与操作手感

## 目标

让业务用户把长任务交给 Flower 后敢于切走：运行中看得懂 Flower 在做什么，完成或需要处理时得到提醒；回来后能找回阅读位置、快速纠错，日常输入与右键操作符合 Windows 习惯。

来源对照：[父任务研究](../11-24-flower-v2-desktop-ux/research/cindy-qone-ux-gap.md) 的「第一档」九项。代码现状：[research/tier1-code-facts.md](research/tier1-code-facts.md)（调研中）。

## 已确认事实

- 工具步骤只显示 `工具步骤 · N 项 · 进行中` 与名称加状态，推理事件不展示。`apps/desktop/workbench/ui/agent.js:207-231`
- 回复只有「复制回复原文」「取消任务」。`apps/desktop/workbench/ui/agent.js:283-287`
- 切换会话时 `thread.reset()` 将滚动归零。`apps/desktop/workbench/ui/agent.js:323-329`
- Markdown 图片按原文输出，链接只放行 http(s) 并交 Host 打开。`apps/desktop/workbench/ui/markdown.js:5-31`
- 主进程清空应用菜单，未注册右键菜单。`apps/desktop/workbench/main.mjs:987`
- 窗口固定以 1282 宽创建。`apps/desktop/workbench/main.mjs:992`
- 另一个 Codex 窗口正在同一工作树修改 `renderer.js`、`main.mjs`、`worker.mjs`、`runtime-host.mjs`、`preload.cjs`、`index.html`、`style.css` 与 `packages/agent-runtime`（共享 pi 长会话续接，见 `11-23-flower-v2-desktop/context-continuity.md`）。第一档的改动面与之高度重叠。

## 候选需求（待逐项确认）

- R1 运行过程可读化：首包前等待态；工具语义标签与目标对象；一轮工作的耗时与动作汇总；推理最新一句与完成后的折叠。
- R2 多任务提醒：侧栏状态（运行中、等你处理、完成未读、出错）；窗口在后台时系统通知并闪烁任务栏，点击回到对应会话；有任务运行时关闭窗口先确认。
- R3 消息操作：失败或取消的请求可重试；最后一条用户消息可编辑后重发；用户消息可复制。
- R4 阅读位置：按会话记住滚动位置；离开底部时出现带新消息数的回到底部按钮。
- R5 回复中的文件路径：工作区内路径可点击预览、在文件夹中显示、复制路径；工作区内本地图片内联显示。
- R6 原生右键菜单：输入框剪切、复制、粘贴、全选；选中文字复制；链接与图片对应操作；文件行与交付卡片「在资源管理器中显示」「复制路径」。
- R7 长粘贴折叠：超过阈值的粘贴文本折叠为可预览、可移除的块。
- R8 历史输入召回：空输入框按 ↑/↓ 翻找本会话已发输入，回到末尾恢复草稿，输入法组合态不触发。
- R9 窗口状态持久化：记住位置、尺寸与最大化，面板外扩部分不计入，显示器变化时回落到可见区域。
