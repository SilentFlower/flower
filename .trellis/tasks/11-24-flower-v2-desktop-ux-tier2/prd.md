# 第二档 追问、队列与会话检索

## 目标

长对话和多轮追问时，用户能就回复中的某段话追问或另开侧边追问、在运行中调整和插入待发消息、按内容找回旧会话、主动腾出上下文；日常提示、中断恢复、交付结果与部门口径也更省心。

来源对照：[父任务研究](../11-24-flower-v2-desktop-ux/research/cindy-qone-ux-gap.md) 的「第二档」。代码现状与行号证据：[research/tier2-code-facts.md](research/tier2-code-facts.md)（下文 §n 指该文件章节）。技术方案见 [design.md](design.md)，执行顺序见 [implement.md](implement.md)。

## 任务组织（2026-11-24 决定）

- 第二档剩余 9 项合并在本任务一次规划、实现、验收，不再拆子任务。按输入区、检索与上下文、零散体验三批实现，每批单独提交。
- 会话导航条已由子任务 [tier2-navigator](../11-24-flower-v2-desktop-ux-tier2-navigator/prd.md) 交付；上下文用量圆环已在第一档 R15 交付，本档只做手动压缩与压缩位置展示。

## 现状要点

- 运行中再次发送即进入共享运行时的请求队列，时间线显示「已排队」，只能取消；停止当前运行后排队请求自动继续；重启后排队请求变为中断。pi 支持运行中插话（`steer`），共享运行时未接入（§1）。
- 回复区没有选中文字操作（§2）；没有输入补全，面板文件行不可拖动（§3）。
- 只有自动检查点，没有手动压缩入口，也不显示压缩发生在哪里（§4）。
- 侧栏搜索只匹配名称与工作区（§5）。
- 中断在首次打开会话时才被修正，启动时不知道哪些会话中断；已有逐条「重试」（§6）。
- 交付物只有 `分析报告.md`、`汇总.xlsx`、`核对报告.md`，没有 PDF 产物（§7）。
- 提示由 `flowerUI.feedback` 在原位显示；删除会话有确认框且立即物理删除（§8）。
- 系统提示固定在 worker 中，没有自定义指令；Desktop 没有企业下发机制（§9）。

## 需求

### R1 选中引用与侧边追问

- R1.1 在一条 Flower 回复正文内选中文字后，选区旁浮出工具条「引用」「侧边追问」；在该选区上右键，菜单提供「复制」「引用」「侧边追问」。选区跨越多条消息或不在回复正文内时不显示工具条，右键菜单维持现状。
- R1.2 「引用」把选中文字以 Markdown 引用块插入输入框光标处并聚焦，多次引用依次追加；插入后超过 16000 字时提示且不插入。
- R1.3 侧边追问（2026-11-24 决定本档做）以打开时主会话已完成的上下文为参考另开一段对话，主会话继续运行、不受影响。显示在右栏，与工作区文件共用停靠、调宽与窄窗覆盖，顶部切换「文件」「侧边追问」；页内顶部为「基于主会话已完成的 N 轮对话」与新建、关闭按钮（页内不重复显示主会话内容，原「以上为主会话的参考历史」措辞会误指上方，2026-11-24 实现时调整）。主会话尚无完成的回答时不可打开。
- R1.4 每个主会话最多一个侧边追问，重启后保留；已有时再打开先确认替换；用户关闭时停止其运行并删除记录（先确认）；删除主会话时一并删除（2026-11-24 决定）。
- R1.5 侧边追问只读：可读取文件与分析工作簿，不生成报告、不写工作区（2026-11-24 决定）。只收文字，不带附件，不排队（运行中只能取消）。
- R1.6 入口：选区「侧边追问」打开侧边追问页并把选中文字以引用块放入其输入框；队列项「侧边追问」把该消息移出队列作为侧边追问的第一条消息发送（附件不随行并提示）。

### R2 排队消息与插话

- R2.1 运行中、待批准或压缩中发送的消息进入输入框上方的队列，不再以「已排队」消息出现在时间线中；每条显示首行文字与附件数。重试、编辑重发同样进入队列。
- R2.2 队列项可在行内编辑文字、移除附件（保持原位置），可删除，可拖动排序，「更多」菜单提供上移、下移（键盘可达）。
- R2.3 当前运行结束后自动发送队首；用户停止运行后队列暂停，显示「已暂停」与「继续」，点继续或再次发送时恢复（新消息排到队尾）。队首发送失败时保留在队首并暂停，Toast 说明原因。
- R2.4 队列按会话保存，重启后保留并处于暂停状态。
- R2.5 插话（2026-11-24 决定：注入当前运行）：运行中的队列项提供「插话」，在当前这一步结束后送入正在进行的回复，模型据此调整后续步骤。送达前该项显示「插话中」；送达后从队列移除，插话内容以气泡显示在该轮回复的对应位置并随会话保存，后续上下文包含它。运行在送达前结束（失败、取消、中断）时该项回到队首并暂停。

### R3 手动压缩

- R3.1 上下文详情卡提供「压缩上下文」：会话空闲且有尚未压缩的已完成对话时可用，运行、排队、压缩中停用；压缩中显示进行状态并可取消。
- R3.2 压缩把迄今的对话归纳为摘要，后续轮次以摘要续接，原始记录仍可在时间线查看。完成后圆环刷新；失败或取消时保留原上下文，Toast 说明原因。
- R3.3 时间线在最近一次压缩（自动或手动）的位置显示分隔「以上对话已压缩为摘要」。

### R4 会话正文搜索

- R4.1 侧栏搜索框在名称与工作区匹配之外，输入 2 个字及以上时同时匹配会话正文（提问与回复，不含工具结果与侧边追问），不区分大小写。
- R4.2 正文命中的会话行下显示最多 3 条命中片段，关键词高亮；最多列出 50 个正文命中的会话。
- R4.3 点击片段打开会话并跳到命中的那一轮，关键词短暂高亮；减弱动效时直接跳转。

### R5 @ 提及与拖入

- R5.1 输入框中在行首或空白后输入 @ 弹出当前工作区可加入对话的文件，按文件名前缀、文件名包含、路径包含排序，最多 50 条；↑/↓ 选择，Enter 或 Tab 确认，Esc 关闭；输入法组合中不触发，补全打开时方向键与 Enter 不触发历史召回和发送。确认后文件作为附件加入（与面板「+」一致），删除 @ 查询文字。
- R5.2 从工作区文件面板把文件行拖到输入框，同样作为附件加入；系统文件拖入保持现状。

### R6 中断恢复

- R6.1 启动后识别上次被中断的会话（最后一条请求为中断，或磁盘上仍是运行、排队中），侧栏顶部显示「N 个任务上次被中断」，列出会话名称（可点击打开）以及「全部继续」「忽略」。
- R6.2 「全部继续」对每个会话以最后一条请求的原输入与原附件重新发送，已发送的会话从横幅移除；「忽略」后本次运行内不再显示。
- R6.3 会话内的中断请求沿用现有「重试」作为继续入口，文案改为「继续任务」。

### R7 交付卡片元信息

- R7.1 `汇总.xlsx` 卡片显示「N 个工作表 · M 行」（不含表头），Markdown 报告显示「约 N 字」；读取失败时不显示元信息。
- R7.2 PDF 页数：当前没有 PDF 产物，本档不做。

### R8 Toast 与撤销删除

- R8.1 复制成功、操作失败、读取历史失败、队列发送失败、压缩结果等瞬时提示改为 Toast：最多同时 3 条，相同文案去重并重新计时，悬停或焦点在内时暂停，可手动关闭；普通 4 秒、错误与带操作的 8 秒；减弱动效时无滑入动画。表单内与审批面板的错误保留原位提示。
- R8.2 ~~删除会话不再弹确认框，改为 8 秒撤销 Toast~~：试用后由 R11 取代，恢复确认框。

### R9 全局指令

- R9.1 设置中新增「全局指令」文本框（最多 4000 字），保存后从下一轮起对本机所有会话生效；为空时行为不变。
- R9.2 会话所在工作区根下存在 `FLOWER.md` 时，其内容同样生效，排在个人指令之后，同部门共用一个目录即可统一口径；最多读取 8000 字，超出部分不读（2026-11-24 决定：个人设置 + 工作区约定文件 `FLOWER.md`）。
- R9.3 两类指令都作为用户口径偏好附加在系统提示之后，不覆盖安全与工具规则；侧边追问同样适用。上下文详情卡显示「已应用全局指令」「已读取 FLOWER.md」，超长时注明「只读取前 8000 字」。

## 试用反馈（2026-11-24）

用户试用第二档候选包后的决定：压缩分隔要能看到且区分自动与手动；删除改回确认框；搜索入口要看得出能搜内容；去掉会话区顶部留白；侧边追问标签直接可用；输入框上方参照 Cindy 渐隐并显示「新消息」胶囊。

- R10 压缩分隔：会话开头存在旧版本创建、缺少用户消息位置的轮次时，跳过这些轮次继续定位，不再整条不显示。检查点记录产生方式（自动或手动），分隔文案为「以上对话已自动压缩为摘要」或「以上对话已手动压缩为摘要」，早期检查点仍为「以上对话已压缩为摘要」；分隔改为胶囊标签加实线。仍只显示最近一次压缩。
- R11 删除会话恢复确认框（取代 R8.2）：确认框注明「删除后无法恢复」，确认后立即删除会话与其侧边追问的记录文件；运行或排队中的会话仍提示先结束任务。去掉撤销 Toast 与 8 秒延迟删除。
- R12 搜索入口：侧栏按钮改为「搜索」，输入框提示「搜索标题或内容…」；只输入一个字时提示「输入两个字以上会同时搜索对话内容」；命中片段标出「提问」或「回复」，左侧竖线归属到会话。
- R13 顶部留白：文件浏览器开关移入标题栏右端（右栏停靠左侧时在左端），会话区不再为它单独留一行。
- R14 侧边追问标签：标签按钮的样式曾盖过 `hidden`，未建立侧边追问时也显示，进入后无法发送。改为有当前会话即显示标签；页内未建立时提示「发送第一条后，以主会话已完成的对话为参考开始」，发送第一条即新建再发送，新建与关闭按钮在建立后才出现；主会话首轮未完成时提示原因并保留输入。
- R15 输入框上方：会话区下方还有内容时底部 44 像素渐隐，滚到底时不渐隐；回到底部按钮在有新消息时展开为「↓ 新消息」胶囊。主会话与侧边追问相同。

## 不做

- 侧边追问的附件、排队、写入，以及多个并存的侧边追问。
- 多次压缩的历史分隔（只显示最近一次）；压缩摘要的查看与编辑。
- 搜索工具结果与附件正文；全文索引落盘。
- 企业统一下发全局指令（归 `v2-company`）；`AGENTS.md` 等其他约定文件。
- PDF 与 DOCX 交付物的元信息。
- 应用启动时自动续跑中断任务（须用户点「全部继续」）。
- 第三档范围（见父任务任务图）。
