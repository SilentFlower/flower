# 第二档 会话导航条

## 目标

长会话里快速找到并跳回某一轮对话：消息列左侧按轮次显示刻度，悬停预览该轮的提问与回复开头，点击跳转，当前阅读位置高亮。来源：2026-11-24 试用时参照其他工作台提出，第二档候选「会话导航条」。交互方案 2026-11-24 由用户选定「照参照：左侧刻度加预览卡」。

## 现状（代码证据）

- 每轮对话是 `#timeline` 中的一个 `article.task[data-request]`，包含用户消息与 Flower 回复；滚动容器为 `#thread-scroll`（`W/index.html:133-136`）。
- `ui/agent.js` 的 `thread(root, scroll, actions, bottom)` 按 `requestId` 维护消息视图，并负责按会话记忆阅读位置与「回到底部」（`W/ui/agent.js:535-595`）。
- 请求记录含 `input`（用户原话）、`text`（回复 Markdown 原文）、`status`、`failure`、附件；渲染层 `timelines` 按会话保存。
- 消息列居中，最大宽度 780 像素加两侧留白（`W/style.css:1474-1486`）。默认窗口下左侧约 120 像素空白，660 像素窄窗只剩 14 像素。

`W/` = `apps/desktop/workbench/`。

## 需求

- R1 显示条件：当前会话至少 3 轮且内容需要滚动时，在消息列左侧留白处竖排显示导航条；轮次不足、内容不需滚动、首页、左侧留白放不下导航条（窄窗）时不显示。
- R2 刻度：每轮一个刻度，按时间顺序从上到下；当前阅读位置所在的轮次刻度加长加深。当前轮次为视口上部三分之一处正在阅读的那一轮；贴底时为最后一轮。轮次很多时导航条在固定高度内滚动，并让当前刻度保持可见。
- R3 预览卡：指针悬停或键盘聚焦刻度时，在刻度右侧显示卡片：第一行加粗为提问（最多两行，只有附件时显示附件名），下面灰字为回复开头（纯文本，最多三行）。运行中尚无正文时显示「正在处理…」，失败、取消、中断时显示对应状态说明。指针从刻度移到卡片上时卡片保持打开，点击卡片与点击刻度效果相同。
- R4 跳转：点击刻度或卡片、键盘回车或空格，滚动到该轮开头（顶部留少量间距）；系统减弱动效时直接跳转，否则平滑滚动。跳离底部后沿用现有「回到底部」按钮。
- R5 键盘：导航条只占一个 Tab 停留点（当前刻度）；↑/↓ 在刻度间移动焦点，Home/End 到第一轮与最后一轮，Esc 收起卡片。刻度有可读名称「第 N 轮：提问开头」。
- R6 一致性：切换会话、流式输出、新提交与历史加载后刻度与当前高亮同步更新；深浅色、强制颜色模式下可辨认；不改变消息列布局宽度。

## 验收标准

- [ ] AC1（R1）2 轮或内容不需滚动的会话不显示导航条；第 3 轮加入且出现滚动后显示；660 像素窄窗不显示，恢复宽窗后重新显示；首页不显示。
- [ ] AC2（R2）滚动阅读时当前刻度随之变化，贴底时为最后一轮；60 轮会话中导航条不超出会话区，当前刻度保持可见。
- [ ] AC3（R3）悬停与键盘聚焦显示提问与回复开头；附件提问、运行中、失败的轮次文案正确；从刻度移到卡片上卡片保持打开。
- [ ] AC4（R4、R5）点击刻度、点击卡片、回车与空格都跳到该轮开头；↑/↓/Home/End 移动焦点，Esc 收起卡片；减弱动效时无平滑滚动。
- [ ] AC5（R6）切换会话、流式输出与新提交后刻度数量和高亮正确；深浅色可读；Desktop `npm test`、`npx biome check apps/desktop` 通过，纯逻辑有单元测试，交互在浏览器夹具中核对。

## 不做

- 会话正文搜索与命中跳转、跨会话导航（第二档其他候选，另行规划）。
- 按内容长度比例分布刻度的缩略图式导航。
- 窄窗下的折叠或抽屉式导航。
